# 관세사 공부방

관세사 1차·2차 시험 공부용 웹앱입니다. 설치 없이 브라우저에서 열리고, 아이폰·안드로이드 홈 화면에 앱처럼 추가할 수 있어요. 한 번 열고 나면 인터넷이 없어도 돌아갑니다.

## 들어 있는 것

| 탭 | 내용 |
|---|---|
| 1차 기출 | 2024~2026년(제41~43회) 1차 4과목 480문제, 최종정답 채점, 문제별 해설, OMR 답안지 진도 |
| 2차 기출 | 2024~2026년 2차 4과목 문제지, 80분 타이머, 문제별 답안 작성 칸 |

| 관세법 지도·카드 | 13개 장 구조 지도(조문 시트, 관련 기출 바로 풀기), 간격반복 플래시카드 77장 |

| 관세율표 | 1~97류 번호 ↔ 품목명 퀴즈, 부별 범위 선택, 전체 표 |

진도와 오답, 2차 답안은 그 기기의 브라우저에만 저장됩니다. 폰과 컴퓨터 사이에 자동으로 옮겨지지는 않아요.

## 깃허브에 올려서 웹앱으로 쓰기 (GitHub Pages)

1. github.com에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 이름은 `customs-study`처럼 정하고, **Public**을 고른 뒤 **Create repository**를 누릅니다.
   - 무료 계정은 Public 저장소에서만 Pages를 쓸 수 있어요. 기출 문제지가 들어 있으니 주소를 널리 공유하지는 마세요.
3. 만들어진 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더(`customs-study`) **안의 파일과 폴더 전부**를 끌어다 놓습니다. `index.html`이 저장소 맨 위에 있어야 해요.
   - 숨김 파일 `.nojekyll`도 함께 올려 주세요. 안 보이면 없어도 동작은 합니다.
5. **Commit changes**를 누릅니다.
6. 저장소의 **Settings → Pages**로 가서 **Source: Deploy from a branch**, **Branch: main / (root)**를 고르고 **Save**를 누릅니다.
7. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/customs-study/` 주소가 뜹니다. 이 주소가 앱 주소예요.

## 아이폰 홈 화면에 추가하기

1. 아이폰 **사파리**로 위 주소를 엽니다(크롬 앱에서는 추가가 안 될 수 있어요).
2. 아래 가운데 **공유 버튼(□↑)** → **홈 화면에 추가** → **추가**.
3. 홈 화면의 '관세사' 아이콘으로 열면 주소창 없이 앱처럼 열립니다.
4. 처음 한 번은 인터넷이 연결된 상태로 각 탭을 한 번씩 열어 두면, 그다음부터는 비행기 모드에서도 열립니다.

안드로이드는 크롬으로 주소를 연 뒤 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 누르면 됩니다.

## 내용을 고친 뒤 다시 올릴 때

- 고친 파일을 저장소에 다시 올립니다(같은 이름이면 덮어써져요).
- `sw.js` 맨 위의 `VERSION` 값을 바꿔 주세요(예: `v1-2026-10-21` → `v2-2026-11-01`). 이걸 바꿔야 폰에 저장된 옛 버전이 새 버전으로 바뀝니다.
- 폰에서는 앱을 완전히 닫았다가 다시 열면 새 버전이 적용됩니다.

## 알아둘 점

- 1차 정답은 큐넷 최종정답(A형) 기준입니다. 2024년 회계학 45번은 전항 정답 처리됐어요.
- 해설은 최종정답을 바탕으로 작성했습니다. 조문 번호나 세부 수치는 시험 전에 최신 개정 기본서와 법령으로 한 번 더 확인하세요.
- 2차 기출에는 모범답안이 없습니다.
